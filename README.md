# AWS EC2 Cloud Administration – Day 2

## 📌 Project Overview

This project demonstrates practical AWS EC2 cloud administration, including vertical scaling, Windows RDP connectivity, and Linux SSH connection using PuTTY.

It helped me develop basic cloud management, remote access, troubleshooting, and server administration skills relevant to IT Support Engineer roles.

## 🛠️ Technologies Used

- AWS EC2
- Windows Server
- Linux
- RDP
- SSH
- PuTTY
- PuTTYgen
